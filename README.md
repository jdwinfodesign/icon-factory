Favicons aren't as big a deal as they used to be, but they still class up the joint when you use them, so why not? Especially when you can just use the "favicons" Python library. Download as a ZIP and run the generate.py script in the generator directory. Whatever image(s) you park in the source directory will automagically get turned into a full set of icons, including favicon.ico, Apple touch images, and MS tiles and be output to the dist directory.
